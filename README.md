# EduGenie - Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant that helps students with personalized study plans, doubt clearing, and notes generation using Google Gemini.

### Features
- Ask any subject doubt and get instant answer
- Generate study notes from topic
- Personalized learning path

### Tech Stack
- Google Gemini API
- Python (app.py), Java (app.java), JavaScript (javascript.js)

### How to Run
1. Clone repo: git clone https://github.com/dgisakthi333-coder/EduGenie
2. Add Gemini API Key
3. Run python app.py
